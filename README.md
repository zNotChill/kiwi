
# kiwi

multiplatform/jvm library full of utils

# packages

`blossom` (JVM)
 - Minestom utilities with DSL builders and other features:
 - Builders:
   - Biomes
   - Bossbars
   - Commands
   - Adventure Components
   - Adventure Keys
   - Dialogs
   - Instance templates
   - Particles
   - Multi-purpose raycasts
   - Sound builders
   - Storage management (volatile/persistent K/V)
 - Extensions:
   - Minestom Scheduler extensions
   - Minestom Color extensions
   - Minestom CommandSender extensions
   - Minestom GlobalEventHandler extensions
   - Minestom Player extensions
   - Minestom Pos extensions
   - Adventure Audience extensions
 - Time utils & timers
 - Server builders

`core` (Multiplatform)
 - The core multiplatform shell of kiwi
 - Colors (w/ Twine support)
   - Adventure extensions **(JVM Only)**
 - Vectors (w/ Twine support)

`network` (JVM)
 - Various networking utils made for Ktor
 - IPv4 & IPv6 parsing
 - TCP & UDP Builders w/ Kiwi Addresses
